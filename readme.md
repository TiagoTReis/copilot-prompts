### PERGUNTA 2: "Qual a diferença entre LEFT JOIN e INNER JOIN?"

**COMO RESPONDER:**
"O INNER JOIN retorna apenas as linhas que têm correspondência em ambas as tabelas. Já o LEFT JOIN retorna TODAS as linhas da tabela da esquerda, mesmo que não tenham correspondência na tabela da direita - nesse caso, os campos da direita ficam NULL.

Por exemplo: se tenho uma tabela de clientes e outra de pedidos, um INNER JOIN só mostra clientes que fizeram pedidos. Um LEFT JOIN mostra TODOS os clientes, incluindo aqueles que nunca compraram (com pedidos = NULL)."

---

### PERGUNTA 3: "Como você lida com dados faltantes (missing values)?"

**COMO RESPONDER:**
"Primeiro, eu investigo POR QUE os dados estão faltando - isso é crucial. Depois, dependendo do contexto:
- Se for uma coluna com muitos valores faltantes e não essencial, posso removê-la
- Se forem poucas linhas, posso remover essas linhas específicas
- Para dados numéricos, posso preencher com média/mediana
- Para dados categóricos, posso criar uma categoria 'Desconhecido' ou usar a moda
- O importante é documentar a decisão e entender o impacto na análise."

---

### PERGUNTA 4: "Como você garantiria que sua análise está correta?"

**COMO RESPONDER:**
"Eu sigo algumas práticas:
1. **Validação dos dados** - Verifico se os números fazem sentido
2. **Sanity checks** - Comparo resultados com benchmarks conhecidos
3. **Peer review** - Peço para alguém revisar minha lógica
4. **Documentação** - Registro todas as transformações
5. **Visualização** - Gráficos ajudam a identificar anomalias rapidamente"
